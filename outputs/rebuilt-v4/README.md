# 曾村视频重建 V4 · 审阅交付

本版重新建立了去程与返程共用的相机、建筑编号、空间坐标和建筑模型。交付包含 **402 个建筑及附属单元**；其中有住宅主体、侧翼、雨棚、屋顶房等，不能把这个数字当作 402 栋独立房屋。

**当前状态：模型、对照资料和复建数据已交付，整体还原质量尚未通过“所有建筑达到红框建筑质量”的最终验收。** 原片对照仍显示密集老屋的院落连接、部分远景建筑、立面和环境细节存在差异。文件可用、几何检查通过、相机误差较低，均不能替代这项外观验收。

建议从 [原视频机位对照](Source_Comparison.html) 开始查看。页面提供 0、44、64、80、90、120 和 256 秒的原片、同机位模型以及透明叠加检查，每个机位都可打开编号与檐口轮廓图。随后在 [三维查看器](Village_Viewer.html) 中旋转模型，或用 [逐栋图册](Building_Catalogue.html) 对照模型双视图与原视频局部。

## 打开与使用

完整解压文件夹后可打开 `Village_Viewer.html`。本次已实际验证本机 HTTP 打开方式；自动浏览器的 URL 安全策略禁止访问 `file://`，直接双击 HTML 的方式未验证。模型、Three.js 和 Draco 解码器已嵌入此 HTML；右侧参考照片和另外两个页面使用包内相对路径，需保留文件夹结构。初次载入较慢时请等候“已载入 402 个建筑及附属单元”。

查看器支持拖动旋转、滚轮缩放、右键平移、编号搜索、单栋隔离、环境开关和六个预设机位。输入 **P011** 可定位原先红框中的建筑。网页版是适合交互的导出版本，最细的栏杆和拟合细线、程序材质的微小变化有简化；要检查完整几何和材质，请用 Blender 打开主文件。

如果浏览器限制直接打开本地页面，在此文件夹运行以下命令，再访问终端所示本机地址的 `Village_Viewer.html`：

```sh
python3 -m http.server 8774 --bind 127.0.0.1
```

## 这轮重建落实的改变

去程与返程已在同一相机重建模型中注册。建筑以统一坐标重新建立轮廓、主体高度、侧翼和屋顶关系；进行了跨镜头去重与连体单元调整，保留处理记录。各建筑按自己的主方向建立墙体，不把整村强行转成同一朝向。

模型按原片能辨认的部位建立平屋顶、瓦屋面、金属棚顶、阳台、柱、楼梯、凹入立面和门窗。原视频照片只用于审阅页面中的参考，不充当模型贴图。主文件的程序材质和独立几何可继续编辑。

遮挡面、很小的屋顶设备和远处细节有推断或简化；部分屋面坡度依据可见檐口和常见构造约束。绝对尺寸没有实测标定，坐标中的米制比例是暂定值。地形、农田、植被用于恢复空间关系，不是测绘级地表。

复建检查已经从本包的数据和脚本实际生成过新模型，402 个单元的编号、构件数、门窗数和网格顶点记录与主文件构建记录一致。这证明冻结数据可以复建，不能证明外观已全面符合原片。

本版使用 Blender 5.2.1 生成和检查。更换 Blender 版本、导入其他三维引擎后的材质与表现未逐一验证。旧版本保留，本包可独立审阅。
