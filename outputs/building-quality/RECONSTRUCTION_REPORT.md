# XZ-Village 整村逐栋重建交付

本次已将视频覆盖范围内识别、去重登记的建筑单元逐一建成可编辑模型。共 300 个编号单元：原红框基准建筑 B001 保留，新增 299 个。单元包括独立房屋、连体侧翼、旧瓦屋面分段和附属小房，不能解读为 300 户居民。

用户已明确允许“自行推测即可，不需要太精确”。本次据此完成遮挡面、远景尺寸与看不清的附属细节；验收对象是完整可编辑的建筑外观及细节层次，真实空间尺寸和每个窗户的原位精度没有得到测量验证。

## 核验结果与边界

最终文件逐栋检查全部通过：299/299。新增建筑含 6,343 个 Blender 对象、758,844 个网格顶点及 4,207 处门窗洞口。重复的小构件按材质整理为网格和曲线组，保留独立网格片、曲线段及原构件名称记录。

原 B001 的 681 个对象及几何 SHA-256 保持一致：`255a0e56df3da9dc34ff01b34bc466c80d72a7cb1320fd116e7ca0504e539bb3`。自动核验覆盖编号与集合一致、墙体范围、楼板与洞口、屋顶细节、排水构件、有效坐标、非退化网格面、平面着色、材质、图像内嵌和无外部链接库。全部 1035 张保留图像已打包。

实际逐栋外观检查覆盖 19 页、299 个单元的正反两个斜视角，并复查修正过的页面。已处理错误平滑着色、照片投影碎片、远景屋顶过窄或扭曲、铁皮接缝越界、在建房误装门窗、轮廓修正后窗洞坐标越界等问题。检查由本次建模 agent 完成，不是第三方测绘验收。

建筑位置与主要屋面来自视频观察和多视角对齐；视频回程区域通过人工对应和屋顶控制点近似并入。整村仍沿用原基准建筑估计的 7.5 米屋宽作为尺度。远端深度、地面标高、隐藏立面、室内布局和细部比例属于估计。道路、池塘、地形与植被保留近似背景，部分地面照片投影存在拉伸与未覆盖区域；它们不在本轮逐栋建筑细节的完成声明内。没有完成室内装修、施工构造、游戏碰撞体或性能优化。

## 在 Blender 中继续编辑

展开 `11 ARCHITECTURE | reviewed numbered buildings`，按 B、O、R、A、N、F、G、C、D 编号定位集合。选择对象后进入 Edit Mode，可用 Select Linked 选择某个独立墙片、窗框或屋面构件；需要独立对象时使用 Separate → Selection 或 By Loose Parts。曲线组保留独立可选样条。原基准建筑在 `01–03 TARGET` 集合中，原对象组织未改变。

文件默认打开整村相机视角和按材质颜色显示的实体视图，便于流畅检查；切换 Material Preview 或 Rendered 查看实际材质。保留了视频参考相机及局部审阅相机。
